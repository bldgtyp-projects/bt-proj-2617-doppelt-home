The envelope recommendations above were developed with code compliance in mind, so that one set of assemblies serves
both the performance goals and the filing. This section summarizes where the project stands. The compliance work
itself, including the tabular envelope analysis and the filing coordination, is a later phase of our scope.

#### The building falls under the Commercial Provisions

The <VarLink hrefKey="narrative.energy_code.link" target="_blank" rel="noopener noreferrer"><Var k="narrative.energy_code.name" /></VarLink>
defines a Residential building to include townhouses having not more than three stories above grade plane. At
<Var k="narrative.user_defined.stories_above_grade" /> stories above grade plane, this house is a Commercial building
for energy-code purposes, whatever its single-family use and R-3 occupancy classification say. The existing building
already exceeded that threshold, so the new penthouse is not what causes it.

The practical consequences are a cap on vertical fenestration area, assembly U-factor requirements in place of the
residential R-value table, and lighting power and lighting control requirements that do not apply to residential work.
The lighting requirements need to reach the lighting designer early.

#### The fenestration ratio clears the cap, which settles the compliance path

Glazing is about <Var k="narrative.user_defined.window_to_envelope_ratio" />% of the modeled thermal envelope area,
and no skylights are planned. Measured against the above-grade wall area the code actually counts, and excluding the
party wall against the conditioned neighbor, the ratio sits well below the 30% cap.

That result matters more than it looks. Under Section C402.1.4 the component-performance equation carries penalty
terms for excess fenestration and excess skylight area. Both go to zero here, so the equation reduces to a
straightforward area-weighted trade-off, and no whole-building ASHRAE 90.1 model is required.

#### The thermal-bridge work counts twice

The 2025 code added linear and point thermal transmittance to the component-performance equation, and it permits an
improved psi- or chi-value to be established by thermal analysis where a detail betters the tabulated value. The
two-dimensional simulations scheduled for this project therefore serve as Passive House documentation and as code
credit from the same run.

One detail matters for an interior-insulated masonry building. The equation assigns a value of zero to thermal bridges
formed by materials at or below a conductivity threshold that softwood sits well under. The embedded wood joist ends,
which are the governing moisture risk on this building, carry no code liability. Steel, concrete and masonry elements
are above the line and do count.
